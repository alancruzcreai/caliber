# Caliber

Lead capture & qualification console — interactive prototype.

**Live demo:** https://alancruzcreai.github.io/caliber/

A high-fidelity, navigable prototype of an operator's console: an AI agent
converses and filters leads across Instagram & WhatsApp, a human qualifies the
hot ones in seconds, and only the best reach the founder's calendar with a
one-page brief.

## Screens

| Screen | What it does |
|---|---|
| Dashboard | KPIs, pipeline funnel, this week's calls, hot leads |
| Conversations | Live AI inbox with transcript + lead context |
| Leads to qualify | One-card-per-lead qualification (Pass / Nurture / Fail) |
| Ads & Theme pages | Creative library, theme-page inventory, scheduler |
| Today's calls | Per-call brief: pain quote, budget, angle, hot buttons |

## Notes

This is a visual prototype with mock data — no backend is connected.
Press **⌘K / Ctrl K** for the command palette.

Built with plain HTML, CSS and vanilla JS. No build step.
